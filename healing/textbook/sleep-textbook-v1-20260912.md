> **读者与用法**：自学者和健康工作者从本章起系统读；只想马上行动的人读第0章就够。本教材每个结论都标注把握程度（四档人话），并可经尾注回到证据层正典核对原文与文献号。

## 第0章 一页行动版（L1）

> 完整版见 `sleep-l1-80yi-20260912.md`，要点如下。

**一句话**：睡好觉靠节律，不靠药——锚住起床时间，失眠先做行为治疗，别信"助眠捷径"。

**七张行动卡**：①固定起床时间比固定入睡更重要，起床后见光、夜里调暗（指南推荐）②失眠第一步是认知行为治疗不是安眠药：平均快睡约19分钟、夜里清醒少约26分钟、试验中无副作用报告（确定）③午睡20–30分钟封顶：天天超1小时心血管风险更高（确定），短午睡较稳（比较确定）④褪黑素只对倒时差、晚睡型生物钟确定有用；当普通安眠药效果小，长期自服安全性不知道⑤咖啡因下午就停：睡前6小时喝仍搅乱睡眠（确定）⑥酒不是助眠剂：快点睡着换后半夜粉碎、做梦睡眠被砍（确定）⑦晚餐睡前3小时吃完，白天多吃菜和粗粮：纤维多深睡多，高糖高脂睡得浅（比较确定）。

**误区速查**：8小时教条（是范围不是处方）｜酒助眠（亏本买卖）｜数羊（越努力越睡不着）｜周末补觉还债（=社交时差）｜老人睡少没关系（失眠仍该治，安眠药对老人更危险）｜火鸡致困（吃撑+酒，不是色氨酸）。

## 第1章 睡眠是怎么工作的（机制）

**学习目标**：读懂"困意"与"生物钟"两套系统；分清一夜的睡眠分期；知道哪些机制是确定的、哪些还在研究。

### 1.1 两套系统决定你几点困（双过程模型）

**睡眠压力**像沙漏：醒着的时候，大脑里一种叫**腺苷**的物质持续积累，越积越困；睡着后它被清空，沙漏倒转。**昼夜节律**像体内时钟：大脑里一个叫**视交叉上核**的"总钟"驱动约24小时的警觉波动，让你该醒时醒、该困时困。困不困、何时睡，是"沙漏水位"和"时钟指针"共同决定的。这个**双过程模型**的框架已被广泛验证（研究已确认）；但具体细节仍有偏离和争论（比较确定·细节仍在研究）。[L3:SLEEP-A1]

### 1.2 一夜的分期：深睡在前，做梦在后

入睡后先经过浅睡，再进入**慢波睡眠**（俗称"深睡"，脑电波又大又慢），多集中在前半夜；夜间**生长激素**的分泌脉冲与深睡时相耦合——深睡是夜间生长激素的主要驱动之一，这层耦合随年龄和激素状态变化，如绝经后减弱（研究已确认）。[L3:SLEEP-A3] 后半夜以**REM睡眠**（快速眼动期，做梦最集中的阶段）为主。记忆方面：深睡支持陈述性记忆（事实与事件记忆）的巩固，方向已确立（研究已确认）；REM对记忆的贡献，学界自己都承认"还在寻找"（还在研究）；REM究竟不可或缺的功能是什么，没有单一共识（不知道）。[L3:SLEEP-A2][L3:SLEEP-A4]

### 1.3 术语表（表1·先定义后展开）

| 术语 | 一句话定义 |
|---|---|
| 睡眠压力 | 醒着越久越困的驱动力，睡眠中消散 |
| 腺苷 | 睡眠压力的代表性信号物质，咖啡因靠阻断它起效 |
| 昼夜节律 | 体内约24小时的生理节律，由生物钟驱动 |
| 视交叉上核 | 大脑里的"总钟"，昼夜节律的指挥部 |
| 双过程模型 | 睡眠压力×昼夜节律共同决定睡眠时机的模型 |
| 睡眠潜伏期（SOL） | 关灯躺下到睡着所用的时间 |
| 睡眠效率（SE） | 躺在床上的时间里真正睡着的比例 |
| 醒后清醒时间（WASO） | 入睡后夜里清醒的总时长 |
| 慢波睡眠（SWS/深睡） | 脑电深大慢波的睡眠阶段，前半夜为主，管修复与记忆巩固 |
| REM睡眠 | 快速眼动期，做梦最集中，后半夜为主 |
| 睡眠片段化 | 夜里反复碎醒，睡眠被切块 |
| CBT-I | 失眠认知行为治疗，成人慢性失眠一线疗法 |
| 刺激控制 | CBT-I组分：床只用来睡，固定起床时间 |
| 睡眠限制 | CBT-I组分：压缩躺床时间，攒够睡意再上床 |
| 睡眠卫生 | 一组作息环境建议；单独做证据弱，不等于CBT-I |
| 时型 | 个人偏早睡（早鸟）或偏晚睡（夜猫）的天生倾向 |
| 社交时差 | 生物钟与社会时间（如周末补觉）的错位 |
| 褪黑素 | 生物钟信号激素，对时差与晚睡相位有效 |
| 延迟睡眠时相（DSWPD） | 生物钟整体后移、想睡睡不着的时相障碍 |
| IARC 2A | "很可能对人类致癌"的证据强度分级（非"必致癌"） |

**小结**：困=睡眠压力+生物钟合力；深睡管修复与记忆巩固（确定），做梦期功能还在研究（不知道）。

## 第2章 失眠了怎么办

**学习目标**：知道失眠第一步该做什么、CBT-I真实效果多大、安眠药何时才考虑。

### 2.1 一线是CBT-I，不是安眠药

**CBT-I**是多种方法的组合：认知治疗（拆掉对睡眠的错误信念）＋刺激控制＋睡眠限制＋睡眠卫生＋放松训练——至少含三项的组合才叫CBT-I，单做"睡前少玩手机"式宣教不算（研究已确认·组合定位）。20项随机对照试验、共1162人的合并分析：入睡潜伏期平均缩短19.03分钟、夜里清醒时间减少26.00分钟、睡眠效率提高9.91%（≈躺8小时多睡约47分钟）；总睡眠时长只+7.6分钟、未达显著——它主要修"睡得着、睡得沉"，不是拉长睡眠；且疗效在治疗后仍维持，全部试验中无不良结局报告（研究已确认）。美国内科医师学会指南把CBT-I列为成人慢性失眠的初始治疗（指南推荐）。[L3:SLEEP-B1]

**决策树（图1）**：失眠≥3个月、每周≥3晚、白天受影响？→是→**第一步CBT-I**（门诊/自助书/数字疗法均可）→4–6周后仍重→复诊：排查其他睡眠疾病、评估是否短期辅助药物（老人尤须慎重，见2.3）。→否（偶尔睡不好）→先做第0章行动卡1/5/6/7，别急着当病治。

### 2.2 越努力越睡不着

"必须睡够X小时"的强迫性努力本身会诱发失眠焦虑（比较确定·模型层）——这是"数羊""看钟算还能睡几小时"越用越糟的原因。行为治疗的起点恰恰是放下数字、放下用力。[L3:SLEEP-B1][L3:canon-E4]

### 2.3 安眠药的反页

老年人使用镇静安眠药与跌倒、骨折风险升高相关（研究已确认·多项观察面）；依赖、耐受、停药反跳为临床共识（比较确定）。对照试验里CBT-I无不良结局报告——它是唯一没有药理副作用的一线（研究已确认）。[L3:SLEEP-E3]

**小结**：失眠首选CBT-I；效果量级是"快睡19分钟、少醒26分钟"，真实且无副作用；安眠药是老年跌倒风险面，留作评估后的选择。

## 第3章 睡好的一天天

**学习目标**：把光、温度、咖啡因、酒、吃，排成一天可执行的节律。

### 3.1 光与温度

晨光锚定生物钟、夜里调暗（指南推荐）。睡前1–2小时洗温水澡/淋浴改善睡眠（研究已确认·系统综述存在；机制="浴后核心体温下降"比较确定）。卧室偏凉更好睡（比较确定·指南级，暂无单独大试验）。[L3:SLEEP-B2a][L3:canon-B2]

### 3.2 咖啡因：6小时也不保险

睡前0/3/6小时三档摄入400毫克咖啡因，三档都客观显著搅乱睡眠——"下午晚些喝没事"不成立，6小时前仍不安全（研究已确认）。且咖啡因清除速度因人而异（CYP1A2酶活性变异）："半衰期约5小时"只是群体近似（比较确定）。实操：截止线个体化，从"睡前6小时"再往前提起步（比较确定·推论）。[L3:SLEEP-B2b][L3:SLEEP-C5]

### 3.3 酒的全谱（表2）

| 酒精效应 | 谱段 | 把握 |
|---|---|---|
| 入睡更快（"助眠"假象来源） | 全剂量 | 确定 |
| 前半夜更深、深睡反常升高 | 高剂量最明显 | 确定 |
| 后半夜睡眠切碎 | 全剂量 | 确定 |
| 第一段做梦睡眠推迟 | 全剂量最可辨识 | 确定 |
| 整夜做梦睡眠比例下降 | 中高剂量 | 确定 |

一句话：以酒助眠=用做梦睡眠和后半夜完整性换入睡速度（比较确定·直推）。[L3:SLEEP-C2][L3:SLEEP-B2c]

### 3.4 吃与睡是双向的

晚进食（严格等热量交叉试验）：更饿、能耗与核心体温下降（研究已确认）；睡前3小时完成晚餐改善胃食管反流（研究已确认）。[L3:SLEEP-C1] 吃什么也进睡眠：自由点吃的当晚比控制饮食的当晚深睡更少、入睡更慢；纤维越多深睡越多、饱和脂肪越多深睡越少、糖越多夜里唤醒越多（研究已确认——但样本仅26人单晚，边界如实标注）。反向也成立：睡眠受限会改变进食（研究已确认·方向级）。[L3:SLEEP-C3] "吃蛋白/火鸡助眠助困"：色氨酸通路机制存在，但常规饭量下效应微小；节日困是餐量+酒（比较确定；"火鸡致困"属类比被夸大，不算证据）。[L3:SLEEP-C4]

**一天时间线（图2）**：起床固定点→晒光→午后停咖啡因→晚餐睡前3小时吃完、多纤维→睡前1–2h温水浴→暗光→固定床时间（困了才上床）。

**小结**：光管节律、凉与浴管入睡、咖啡因管"别高估安全窗"、酒管"别信假象"、饭管深睡。

## 第4章 补剂与药物真相

**学习目标**：认清哪些补剂在哪件事上有证据、哪些压根不知道。

### 4.1 分级表（图3）

| 补剂 | 用的场景 | 把握 |
|---|---|---|
| 褪黑素 | 倒时差 | 确定·有效 |
| 褪黑素 | 晚睡型生物钟（DSWPD） | 确定·有效（指南推荐+试验） |
| 褪黑素 | 普通原发失眠 | 比较确定·有效面窄、效应小 |
| 褪黑素 | 长期（数月以上）自己吃 | 不知道·安全性数据不足 |
| 镁 | 助眠 | 不知道·未找到支持的正性证据汇总 |
| 缬草 | 助眠 | 不知道·证据不一 |
| 甘氨酸 | 睡眠受限者的主观日间表现 | 比较确定·仅小样本正信号 |

原则：**"不知道"档=别花钱等证据，更别给孩子长期吃**（褪黑素儿童长期结局同样未闭合）。[L3:SLEEP-B4a][L3:SLEEP-B4b][L3:SLEEP-E2]

### 4.2 处方安眠药

见2.3：老年跌倒骨折风险（确定）、依赖反跳（比较确定）；CBT-I是唯一无药理副作用的一线。[L3:SLEEP-E3]

**小结**：褪黑素是"时相药"不是"安眠药"；镁与缬草停留在"不知道"；已确诊失眠者先CBT-I。

## 第5章 特殊人群

**学习目标**：老人、轮班者、孕产人群各自的确定结论与诚实边界。

### 5.1 老人

深睡与生长激素耦合随年龄减弱（研究已确认）——老人"睡得浅"有生理基础；但"失眠不用管"不成立：失眠仍该治，一线仍是CBT-I；老人用镇静安眠药跌倒骨折风险升高（研究已确认），是第0章误区"老人睡少没关系"的完整答案。[L3:SLEEP-A3][L3:SLEEP-B1][L3:SLEEP-E3]

### 5.2 轮班与夜班

涉及昼夜节律打乱的夜班工作，被国际癌症研究机构（IARC）列为2A类——"很可能对人类致癌"。注意这是**证据强度分级**，不是"上夜班必得癌"；机制候选为褪黑素抑制与节律扰乱（分类事实确定，机制归因比较确定）。[L3:SLEEP-D3] 周中欠觉周末补造成的"社交时差"与肥胖指标、抑郁症状相关（研究已确认·观察性；因果方向不知道）。你是早鸟还是夜猫有遗传基础，但是多基因小效应——别信"单个基因决定时型"（研究已确认；遗传度数值不知道）。[L3:SLEEP-D2][L3:SLEEP-D1]

### 5.3 孕产（诚实边界）

本教材证据底座（sleep-canon v1·24条断言）未覆盖孕产期睡眠的干预与用药结论——**这一格当前是"不知道"，请勿采信任何未标注证据来源的说法**；就诊时以产科与睡眠专科的面对面评估为准。

**小结**：老人治失眠别先拿药；夜班风险是分级不是判决；孕产宁空勿编。

## 第6章 常见问题（FAQ）

1. **一定要睡够8小时吗？** 不是。8小时是人群均值不是处方；权威推荐是范围（成人7–9小时）。以"白天功能无损、不靠闹钟自然醒"为锚。刻意睡9小时以上"养生"没有证据。[L3:SLEEP-F2][L3:SLEEP-E1]
2. **睡眠时长与健康是什么关系？** 之前大规模汇总提示U形关联：睡太短与太长都与更高死亡风险相关（研究已确认·关联）；但"长睡致病因"还是"病因致长睡"分不清（不知道）。[L3:SLEEP-E1]
3. **有天生觉少的人吗？** 有，但极罕见：某些家族基因突变携带者每天睡不到6.5小时也无损害（研究已确认）。这是突变不是习惯，练不成。[L3:SLEEP-F1]
4. **睡不着数羊有用吗？** 没用。强迫性入睡努力本身加重失眠焦虑（比较确定）。起身暗光下做无聊的事，困了再回床。[L3:canon-E4]
5. **喝酒助眠到底行不行？** 不行。入睡快是真的，代价是后半夜切碎+做梦睡眠被推迟削减（研究已确认）。[L3:SLEEP-C2]
6. **褪黑素是安眠药吗？** 不是。它是时相信号：倒时差、晚睡型生物钟确定有效；普通失眠效果小；长期自服安全性不知道。[L3:SLEEP-B4a][L3:SLEEP-E2]
7. **镁片/缬草助眠吗？** 不知道。尚无找到的支持性证据汇总，别为"可能有用"付费。[L3:SLEEP-B4b]
8. **午睡多久合适？** 20–30分钟封顶（比较确定）；天天午睡超1小时与心血管风险升高相关（研究已确认·关联；也可能是健康问题的标志，因果不知道）。[L3:SLEEP-B3]
9. **咖啡几点后别喝？** 睡前6小时已会搅乱睡眠（研究已确认）；代谢慢者更早。没有统一答案，从"午后停"起步试。[L3:SLEEP-B2b][L3:SLEEP-C5]
10. **做梦多说明睡得好吗？** 分不清。做梦期功能本身还在研究（不知道）；别用梦多梦少评睡眠质量。[L3:SLEEP-A4]
11. **周末补觉能还债吗？** 补不完。周中欠、周末补=社交时差，与肥胖、抑郁相关（研究已确认）。[L3:SLEEP-D2]
12. **CBT-I和冥想放松是一回事吗？** 不是。放松只是CBT-I五个组分之一；有效成分是多模态组合（至少三项）。[L3:SLEEP-B1]

## 第7章 自测（10题·带答案）

1. 决定"几点困"的两大系统是？**答**：睡眠压力（腺苷积累，沙漏）与昼夜节律（生物钟）。[L3:SLEEP-A1]
2. 前半夜为主的睡眠阶段及其一项确定功能？**答**：慢波睡眠/深睡；支持陈述性记忆巩固、驱动夜间生长激素脉冲。[L3:SLEEP-A2][L3:SLEEP-A3]
3. 成人慢性失眠的一线治疗与代表性效应量？**答**：CBT-I；入睡约快19分钟、夜间清醒约少26分钟、睡眠效率+9.91%、无不良结局报告。[L3:SLEEP-B1]
4. 为什么"单做睡眠卫生"不等于CBT-I？**答**：CBT-I要求≥3组分组合；卫生宣教单独做证据弱。[L3:SLEEP-B1]
5. 判断：褪黑素对所有失眠都有效。**答**：错。确定有效面是时差与晚睡型生物钟；普通失眠效果小；长期自服安全性不知道。[L3:SLEEP-B4a][L3:SLEEP-E2]
6. 酒精对睡眠的"交易"是什么？**答**：入睡更快，换后半夜破碎、做梦睡眠推迟与减少。[L3:SLEEP-C2]
7. 咖啡因截止线为什么应个体化？**答**：清除速度因人（酶变异）差异大，"5小时"只是群体近似；且睡前6小时已证实扰睡。[L3:SLEEP-C5][L3:SLEEP-B2b]
8. "老人应该少睡、失眠不用治"错在哪？**答**：深睡随龄减少属实，但失眠仍应治疗；老人安眠药跌倒骨折风险升高，一线仍是CBT-I。[L3:SLEEP-A3][L3:SLEEP-E3][L3:SLEEP-B1]
9. 午睡证据的U形指什么？哪部分还不确定？**答**：长午睡（≥60分钟/天）与心血管风险升高相关（RR1.82）；20–30分钟安全窗是推断；因果方向不知道。[L3:SLEEP-B3]
10. IARC把夜班列为2A类，正确的理解是？**答**：证据强度分级"很可能对人类致癌"，非"夜班必致癌"；机制归因仍是候选模型。[L3:SLEEP-D3]
