# 《老》教材 v1——寿命的诚实账本

> **读者与用法**：自学者与健康工作者从第1章系统读；只想马上行动的人读第0章就够。本册与其他分册不同之处是一条诚实基石：**人体"延寿硬证据"至今为零**——所以全书把"确定"二字看得很紧，每个结论都标把握程度，并可经尾注回到证据层正典核对原文与文献号。

## 第0章 一页行动版（L1）

> 完整版见 `aging-l1-80yi-20260912.md`，要点如下。

**一句话**：没有任何补剂、药物或吃法被证明能延长人的寿命（这一条确定）；值得花力气的是便宜事：动、睡、把饭吃对。

**七张行动卡**：①动起来性价比第一：有氧+抗阻，握力步速练得上（确定）②老年蛋白当下限：健康1.0–1.2克/公斤/天，生病1.2–1.5以上，每餐25–30克（指南共识）③老人别饿自己：极端少吃=肌少+骨松+免疫三重风险（确定）④中年控热量10–15%小缺口即可，两年试验做得到、肌力不掉（确定），能否延寿不知道⑤最便宜的衰老体检=握力+步速+心肺适能（比较确定）⑥查血顺路三项：炎症指标、糖化、脂蛋白(a)；别买衰老套餐（确定）⑦不烟少酒：酒毁睡眠见《睡》册；烟本册账本未单列。

**误区速查**：补剂延寿（终点不动）｜年轻血回输（人体无数据）｜热量越少越长寿（老人反向）｜生物年龄可测可逆（数字动≠人变年轻）｜雷帕霉素二甲双胍神药（人体不知道）｜家用桑拿房（证据档位不够大额开支）。

## 第1章 诚实基石：人体延寿硬证据是零

**学习目标**：理解为什么"延寿"宣称都要先过同一道关；学会识别"替代指标"话术；掌握全书使用的四档人话。

### 1.1 那道所有宣称都要过的关

先立一个事实，它是本册的地基：**至今没有任何一项干预——少吃、药物、补剂——在人体以"死亡或衰老硬结局"为终点完成过随机对照试验**。热量限制的两年人体试验（CALERIE）没有死亡终点；著名的二甲双胍抗衰试验（TAME）至今仍在"寻求评估"阶段、没有完成；所有抗衰药物在人体只有小样本、短期、替代指标层面的研究。[L3:F2][L3:B1][L3:B6]

这不是"科学不行"，而是寿命研究天生困难：人活几十年、试验只能做几几年、不能用命令随机分配人的余生。所以诚实的问题是从来不是"这东西能不能延寿"（没人知道），而是"它在人体做到了哪一层"。[L3:F2]

### 1.2 替代指标陷阱：血指标动了，人没动

**替代指标**就是"替身演员"：真正想看的是"多活几年、少病几年"（硬结局），但实验里测的是"血里某分子变多了、某个分数变小了"。替身能代替主角吗？本册最重要的案例是NAD前体补剂（NR/NMN）：口服确实让全血NAD+升到约2倍（研究已确认），但在12周二期随机试验里，主要终点认知功能、全脑血流、血压全部没有改善（研究已确认）。血指标动、终点不动——这是"替代指标已证、临床获益未证、然后卖给健康人"这条商业流水线的标准开头。[L3:B7][L3:E1]

同类陷阱贯穿全册：端粒长度商业检测、氧化应激面板（预测增量未证）；表观遗传时钟的"逆转"宣称（第4章详述）；"年轻血回输"（动物有信号、人体零数据）。识别口诀只有一句：**问终点，不问替身**。[L3:C3][L3:C1][L3:B9]

### 1.3 物种分层：老鼠的寿延不是人的寿延

小鼠中年才起步吃雷帕霉素都能延长寿命——这是哺乳动物层面最硬的抗衰证据（研究已确认·动物）。但从"小鼠有效"到"人怎么吃、吃多少、安不安全"之间隔着剂量翻译、副作用谱、几十年随访三道没有解决的断层（不知道）。本册铁律：**动物证据永远不自动外推到人**；看到"实验证明延寿"先问一句"什么实验、什么物种"。[L3:B5][L3:A]

### 1.4 术语表（图表1·先定义后展开）

| 术语 | 一句话定义 |
|---|---|
| 硬结局 | 死亡、重大疾病等不需要解释的结局；与"替身"相对 |
| 替代指标 | 用来代替硬结局的中间测量（血指标、分数、影像） |
| 随机对照试验（RCT） | 把人随机分组、一组干预一组对照的严格试验 |
| 热量限制（CR） | 在营养充足前提下长期减少热量摄入 |
| CALERIE | 首个人体两年CR随机对照试验 |
| 进食窗口（TRE/16:8） | 把一天进食压缩到固定时段的轻断食形式 |
| 衰竭标志 | 描述"为什么会老"的十二个细胞与分子层面变化 |
| 表观遗传时钟 | 按DNA甲基化图谱估算"生物年龄"的研究工具 |
| DunedinPACE | 一种测"衰老速度"的时钟指标 |
| mTOR | 细胞生长主开关之一；雷帕霉素抑制它 |
| 雷帕霉素 | 免疫抑制处方药；动物延寿证据最强 |
| 二甲双胍 | 降糖处方药；抗衰用途未经硬试验证实 |
| TAME | 二甲双胍抗衰临床试验；至今未完成 |
| NAD+/NR/NMN | 细胞能量代谢分子及其口服前体补剂 |
| senolytics | 清除"僵尸细胞"类药物；人体无硬结局数据 |
| 自噬 | 细胞回收折旧零件的机制 |
| 端粒 | 染色体末端保护帽，随分裂磨损 |
| 慢性低度炎症 | 老年体内常年低烧的炎症状态 |
| 肌少症 | 肌肉量与力量随龄流失导致的失能倾向 |
| 合成代谢抵抗 | 老年肌肉对蛋白/运动的合成反应变迟钝 |
| 握力/步速/VO2max | 三项最便宜的心肺与肌肉适能测量 |
| hsCRP/HbA1c/Lp(a) | 炎症、平均血糖、遗传性心血管风险三项血指标 |
| 瘦体重 | 体重里除脂肪外的部分，大头是肌肉 |

**小结**：问终点不问替身；动物不外推；"延寿N年"一律当作推算。

## 第2章 为什么会老：十二大标志是地图不是体检单

**学习目标**：知道老化研究的解释框架长什么样、它能用来干什么、不能用来干什么。

### 2.1 框架本身

2023年正式版提出十二条"衰竭标志"，入选标准有三条：随年龄出现；在实验里加重它会加速老化；干预它可减速（动物中可逆转）老化。这个框架本身是可靠的学术共识（研究已确认）。十二条用一句话说：DNA修不完、染色体保护帽越用越短、基因开关图谱漂移、折旧蛋白清不动、细胞回收站停摆、营养感应油门刹车失灵、发电站老化、"僵尸细胞"不搬家还放毒、换零件的后备军枯竭、邻里串话出错、低度炎症常年在烧、肠菌群产物谱变坏。[L3:A]

### 2.2 怎么读这张地图（图表2）

| 读法 | 对不对 |
|---|---|
| 作为"为什么人会老"的解释骨架 | 对（研究已确认·框架级） |
| 作为干预靶点的研究地图 | 对：第3章每项干预都能映射回某几个标志 |
| 作为"检测几个标志=知道你多老"的体检单 | 不对（比较确定·学界自己的批判） |
| 认为"逆转某个标志=逆转衰老" | 人体未证（不知道） |

两条诚实注脚：动物证据与人体证据在每个标志上差距很大（如"僵尸细胞"清除在小鼠改善功能，人体只有小试点）；学术圈自身对该框架的批评已登上主刊——标志是情境依赖的调控机制，不总符合疾病定义，任何一条不满足三标准就该除名。[L3:A]

**小结**：地图很有用，但把地图当体检单、把动物当自己，是这一章要防的两个错。

## 第3章 干预分级账本：谁在哪个证据档

**学习目标**：把常见"抗衰手段"按证据档位排成一页账；知道每项的确定面、比较确定面和不知道面。

### 3.1 运动：账本第一名

观察性证据方向一致、跨人群剂量反应清晰：心肺适能越高、全因死亡越低（比较确定·强关联）；随机试验层面，有氧训练确实提升心肺适能（研究已确认），抗阻运动配合蛋白改善老年人步速与握力（研究已确认·汇总级）。正典给它的定性是"目前证据性价比最高的抗衰干预"。具体练法与力量处方见《动》册 `move-textbook-v1-20260912.md`。[L3:B3]

### 3.2 睡眠：几乎免费的抗衰轴

睡眠时长/质量与全因死亡呈U形关联（比较确定·关联级）；机制与处方不在本册重复，见《睡》册 `sleep-textbook-v1-20260912.md`——其中与老年直接相关的一条：老人用安眠药跌倒骨折风险升高（研究已确认）。[L3:B4]

### 3.3 热量限制：人体证据最强、寿命终点仍不知道

两年严格试验（CALERIE）的事实面：非肥胖成人执行约15%热量缺口、12个月减重约8公斤、微量营养素保持充足、肌力不减（研究已确认）；代谢替代指标改善但效应随依从性回落（研究已确认）。对寿命本身的效果——不知道（无死亡终点、动物40%限食不能外推）。可行动档是10–15%适度缺口+营养质量优先，且仅限非肥胖成人；老年与低体重者反向（第5章）。要省的钱：极端限食训练营、"断食代餐包"、无依从性验证的订阅APP——CR的真实成本是食物秤加耐心。[L3:B1]

### 3.4 断食窗口没有额外的魔法

把热量限制装进16:8窗口，减重来自自发少吃，等热量下与常规热量限制无差（研究已确认）；轻断食对人的寿命效果不知道。老年方向的关键根本不是"禁食更狠"，而是蛋白时序——见第5章。[L3:B2]

### 3.5 处方药双星：动物之王与未完成试验

雷帕霉素：中年小鼠起始喂药延长雌雄中位与最大寿命，跨中心复现（研究已确认·动物）；人体只有小样本免疫替代终点试验，无衰老结局RCT（不知道）；副作用真实——口腔溃疡、免疫抑制、血糖血脂扰动、伤口愈合延迟，剂量方案在人体无共识。二甲双胍：分子机制成立（比较确定），但其抗衰试验TAME至今未完成，糖尿病人群的观察性获益对非糖尿病人外推性不知道；自行服药的副作用（B12缺乏、胃肠道）倒是确定的。两药的共同坑：处方药代购、自定剂量、无监测"长寿诊所"。[L3:B5][L3:B6][L3:E3]

### 3.6 NAD前体与静脉输注：本册"最清晰的不值得"

口服NR升血NAD+约2倍属实，但主要临床终点不动（研究已确认）；健康人群获益不知道；静脉NAD输注缺乏临床验证。月费几十到几百美元买一个血数字、按次几百美元打点滴——是"替代指标陷阱"最清晰的消费案例。[L3:B7][L3:E1]

### 3.7 桑拿与候选名单

桑拿的关联证据来自芬兰中年男性队列随访约28年：高频使用者全因与心血管死亡更低（比较确定·自报频次、单一性别单一国家）；30分钟桑拿引起免疫细胞动员是真的生理事件，但不等于结局证据（比较确定）。家用高端桑拿房=把大额资本开支押在关联证据上；健身房桑拿已覆盖可行动面。其余候选一行档：清除僵尸细胞药、亚精胺、表观重编程——人体硬数据全部为零（不知道）。另有一条警示：长寿干预在两性中效应常不同，"人均有效"的宣称都值得怀疑（比较确定）。[L3:B8][L3:B9]

## 第4章 测什么：替代指标陷阱与廉价三件套

**学习目标**：会选检测——知道哪些测量便宜且强、哪些昂贵且说不清。

### 4.1 "生物年龄"钟：科研金标准，还不是决策工具

表观遗传时钟是目前最成熟的生物年龄量化工具，与死亡风险预测相关（比较确定）。但它有个关键局限已被实证：**时钟是动态响应的**——12周饮食干预就能移动"衰老速度"轨迹（研究已确认）。这意味着"钟的数字变小"分不清是"真的年轻化"还是"短期代谢适应"。学术批判已进主刊：钟捕捉的是分子签名，对疾病与可干预性的解释力依赖情境（比较确定）。实用档：自费约200–500美元，只配做多年间隔的基线追踪，不做单次决策依据，更不为"降钟"买补剂。[L3:C1][L3:E1]

### 4.2 廉价强预测三件套

握力：跨17国大队列证实是心血管死亡分层的简单工具（比较确定·强）；步速：3万多人汇总显示与预期生存强分层，而且一年内步速改善本身预示更好的8年生存（比较确定·强）——"能改善"这件事让它从算命变成了行动信号；VO2max：可测的适能硬指标（手表估算属于代理）。一排下来：握力计百元级+手机秒表测4米步速+年度心肺适能——性价比优于任何高价"生物年龄"检测（比较确定·推断）。[L3:C2]

### 4.3 顺路的血与不推荐的套餐

hsCRP（慢性低度炎症读数）、HbA1c（代谢轴）、Lp(a)（遗传决定、一次检测终生分层）——都在常规体检顺路范围内（研究已确认·检测共识）。不推荐：端粒长度商业检测、氧化应激面板等无验证"衰老套餐"（预测增量未证）。[L3:C3]

### 4.4 决策树（图表4）：现在就能做的三件便宜事

```
【问：你在哪一档？】
├─ 65岁以上／生病住院中／体重偏低
│   ├─ 第一件：蛋白当下限——1.0–1.2克/公斤/天
│   │          生病提到1.2–1.5+，每餐25–30克（第5章）
│   ├─ 第二件：抗阻+有氧起步，目标握力与步速
│   └─ 第三件：禁反向限制（不轻断食、不狠限热量）
│              多病共存者所有调整遵医嘱
├─ 65岁以下·超重
│   ├─ 第一件：有氧+抗阻（《动》册）
│   ├─ 第二件：睡够（《睡》册）
│   └─ 第三件：热量10–15%小缺口+营养质量

    ├─ 第一件：同上运动

【所有人不买】NAD补剂与输注·端粒检测·衰老套餐·时钟单次解读·处方药自购
```

## 第5章 老年专属：蛋白下限与肌少防线

**学习目标**：掌握本册行动价值最实在的一章——老年人怎么吃、怎么练、什么不能做。

### 5.1 把蛋白上限思维反转为下限思维

年轻人讨论蛋白常问"会不会太多"，老年人的问题恰恰相反：老年肌肉有**合成代谢抵抗**，同样的饭量建肌肉的效率变低，所以每餐需要约25–30克蛋白才能过"合成阈值"，全天健康状态1.0–1.2克/公斤体重，生病、住院、受伤等应激状态上调到1.2–1.5克以上（指南共识；部分上层区间数值为指南正文口径、摘要级核验）。肌肉与骨是力学加内分泌的耦合单元，蛋白同时撑两者（研究已确认）。[L3:B2][L3:D]

### 5.2 老年反向限制：明确禁止清单

热量限制与禁食模式放到老年=肌少+骨密度+免疫三重风险（研究已确认·各证据形态如正典所标）；低体重老人"再限一口"是错误方向；BMI 22–28的老年不必追热量限制（比较确定）；一日一餐式 OMAD 与每餐蛋白阈值直接冲突，老年及肌少风险者禁用（指南级）。[L3:E2][L3:B2]

### 5.3 减重时代的新风险

减重药物（GLP-1类）伴随瘦体重下降，老年、低肌量、快速减重者是高危人群；预防三件套=基线体成分评估+抗阻运动+足量蛋白（研究已确认·综述级）。热量限制自身的肌信号也已在两年试验中可见——腿瘦体重轻度下降但肌力不减；年轻成人可承受，**老年人同法风险放大**（研究已确认→老年外推为模型推断）。[L3:D]

### 5.4 医疗边界

多病共存老人常同时用多种处方药，任何饮食结构、运动强度、断食安排的调整都可能改变药物作用与跌倒风险——**先问医生，再动手**；正典副作用面（处方药自服、无监测长寿诊所）对老人尤其适用。本册提供的是证据地图，不是处方。[L3:E3][L3:F4]

**小结**：老年章的全部内容可以压成一句话——蛋白当下限、抗阻保肌肉、别反向限制、用药遵医嘱。

## 第6章 花钱指南：市场泡沫的识别法

**学习目标**：不用记住每个产品，只需记住一个模式。

泡沫的标准流水线：**替代指标已证 → 临床获益未证 → 卖给健康人**。三个实证：NAD前体（血指标动、终点不动）；静脉NAD诊所（零验证）；"逆转生物年龄"文献重灾区（多为小样本、无对照、终点是钟的数字而非结局）。结构性背景：检测与补剂产业共享"生物年龄"叙事，连行业综述本身也存在利益独立性问题（比较确定·正典自主标注）。守则三条：动物模型≠人体事实；替代指标≠结局；单臂无对照≠有效。与抗衰直接相关的"别花"清单：NAD补剂与输注、端粒商业检测、家用桑拿房资本开支、处方药代购、无监测长寿诊所套餐。补剂通用鉴别法见《补剂真相》册 `supplement-textbook-v1-20260912.md`。[L3:E1][L3:C1]

## 第7章 常见问题（FAQ）

1. **那到底有没有办法活得久一点？** 有方向、没数字。运动、睡眠、蛋白、适度热量管理在各自档位上有据可依，健康跨度（无失能年数）的证据比绝对寿命更强；"延寿N年"全是推算。[L3:F1][L3:F2]
2. **人体延寿试验真的一个都没有？** 以死亡或衰老硬结局为终点的RCT至今为零：CALERIE无死亡终点、TAME未完成——这是正典的定谳，不是本册保守。[L3:F2]
3. **NAD补剂那么火，一点用没有？** 升血NAD+是真的（确定）；认知、脑血流、血压等临床终点不动（确定）；健康人获益不知道。"花钱买血指标"是最准确的描述。[L3:B7]
4. **"生物年龄"测出来比实际年龄小，该高兴吗？** 可以参考，别当成绩。钟的数字受短期饮食影响，分不清真年轻与代谢适应；更不该为"降钟"买补剂。[L3:C1]
5. **老年人能做16:8轻断食吗？** 不建议。与每餐25–30克蛋白阈值冲突，老年=肌少+骨+免疫三重风险；低体重老人是明确错误方向。[L3:B2][L3:E2]
6. **老人蛋白吃多少？怎么分？** 每天1.0–1.2克/公斤（健康）到1.2–1.5克以上（患病应激），分三餐、每餐25–30克。肾病等特殊状况由医生个体化调整。[L3:B2][L3:D]
7. **吃减重药的老人要额外注意什么？** 瘦体重下降——基线体成分评估+抗阻运动+足量蛋白三件套；老人是高危人群。[L3:D]
8. **雷帕霉素网上很多人在吃，能跟吗？** 不跟。动物之王是真的，人体剂量、安全、效果全不知道，副作用（免疫抑制、血糖血脂、伤口愈合）真实；自购自服是拿处方药赌不知道。[L3:B5][L3:E3]
9. **桑拿到底值不值得坚持？** 顺手值，置产不值。关联证据来自芬兰中年男性队列；健身房桑拿已覆盖可行动面，家用高端桑拿房是大额开支押在"比较确定"档。[L3:B8]
10. **握力、步速怎么自测？** 握力计（百元级）按说明书测最大值；4米正常步速用手机秒表；VO2max看年度体检或运动实验室。重点不是单次数值，是逐年趋势与"能不能改善"。[L3:C2]
11. **"年轻血回输"呢？** 动物有信号，人体零数据，正典列在"宁空勿编"档——商业机构的任何宣称都无人体依据。[L3:B9]
12. **我父母多种慢病、吃七八种药，这本册子适用于他们吗？** 原则适用（蛋白、防跌倒的肌肉训练方向），但剂量、强度、饮食结构调整必须经他们的医生——多病共存+多药是本册明确的医疗边界。[L3:E3]

## 第8章 自测（10题·带答案）

1. 本册的"诚实基石"是哪一句？**答**：人体以寿命/衰老硬结局为终点的RCT至今为零；一切延寿宣称止步于替代指标。[L3:F2]
2. NAD前体的证据结构是什么？**答**：血NAD+升约2倍（确定）+临床主要终点不动（确定）+健康人获益不知道。[L3:B7]
3. 为什么"时钟数字变小"不能证明人变年轻？**答**：钟是动态响应的，12周饮食干预即可移动数字，分不清真年轻化与短期代谢适应。[L3:C1]
4. 动物证据使用的两条铁律？**答**：动物模型不自动外推到人；"实验证明延寿"先问物种与终点。[L3:A][L3:B5]
5. 老年蛋白处方的三个数字？**答**：健康1.0–1.2克/公斤/天；患病应激1.2–1.5克以上；每餐25–30克过合成阈值。[L3:B2]
6. 为什么老年人是"下限思维"？**答**：合成代谢抵抗——同样蛋白建肌效率下降，缺蛋白的代价（肌少、跌倒、失能）远大于"吃多"的担忧。[L3:B2][L3:D]
7. 廉价强预测三件套是哪三项？比什么强？**答**：握力、步速、VO2max；性价比优于高价生物年龄检测，且步速改善本身预示更好生存。[L3:C2]
8. 泡沫流水线三段式？**答**：替代指标已证→临床获益未证→卖给健康人。[L3:E1]
9. 判断：热量越少越长寿。**答**：错。非肥胖成人10–15%适度缺口有据；极端限制在老人=肌少+骨松+免疫三重风险，低体重老人反向。[L3:B1][L3:E2]
10. 多病共存老人用本册的三条边界？**答**：饮食结构调整、运动强度、任何断食安排先经医生；处方药不自购自服；本册是证据地图不是处方。[L3:E3]
