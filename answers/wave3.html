⑱ 皮肤老出状况（湿疹/皮疹/银屑病）怎么办？

一句话答案：皮肤反复出状况多数不是「没洗干净」，是皮肤屏障和免疫在报警——温和清洁加保湿是基线；反复发作、大片扩散或痒到睡不好，去看皮肤科。

分情况

  1. 干燥、痒、脱屑反反复复（湿疹方向）——方向是护屏障不是猛清洁：温水短时洗、洗后趁湿保湿、避开过热烫洗和强力清洁品（模型级通行护理·库卡为机制层研究照录·生活层从屏障机制转写）。
  2. 边界清楚的红斑鳞屑、冬重夏轻（银屑病方向）——它不传染，不必自我隔离；确诊与长期管理归皮肤科。
  3. 接触某样东西后起疹（接触性皮炎方向）——库卡锚行的逆操作是律3 吃真食物（证据级 A）加律4 间歇与留白（B+），方向是减少慢性刺激的叠加；可以记「接触—发作」对照日记帮自己找诱因。
  4. 熬夜压力大赛痘——走睡眠与压力线：规律睡眠（律1）加减压（见焦虑卡），皮肤常跟着整体节律好转。

红旗线（立即就医）

  • 皮疹伴高热、迅速扩散、化脓 → 当天就医（模型级通行红旗·库红旗表无皮肤专行·如实记）。
  • 用新东西后全身起疱、脱皮、口腔破 → 立即急诊（模型级通行红旗·本卡不展开）。

依据与边界：以上为模型级生活参考（非诊断）；库内皮肤锚卡主体为机制层研究照录（化合物记录零转写进建议层）；皮肤科诊断、外用内服方案一律归医生。

⑲ 甲状腺指标异常/查出结节怎么办？

一句话答案：甲功单子不是判决书——甲减是系统运行偏慢、甲亢是偏快，多数可以长期管理；要做的不是自查互猜，是把复查和治疗线交给内分泌科。

分情况

  1. 怕冷、乏力、体重悄悄涨、TSH 偏高（甲减方向）——库内主锚卡（关联 2917 度）为机制层研究照录；生活底座=睡足（律1）加吃真食物（律3）；替代治疗的启动与否、怎么调，归内分泌科。
  2. 心慌、手抖、怕热、消瘦（甲亢方向）——库卡逆操作=律7 单点注意力加律8 持续学新（信息流定位照录），给的是「把整体刺激降下来」的方向：浓茶咖啡因先留出空档；治疗面归医生。
  3. 体检查出结节——库内无结节专卡（UNKNOWN 如实标，宁缺勿编）：结节不等于癌，多数是随访观察；随访节奏与是否穿刺归医生，不靠网络自查下结论。
  4. 孕期甲功异常——归产科加内分泌双面管理，本卡不展开。

红旗线（立即就医）

  • 突发呼吸困难（颈部肿物压迫方向）→ 立即急救（红旗表行3·急症面）。
  • 高热+心跳极快+烦躁意识乱（甲亢危象方向）→ 立即急诊（模型级通行红旗·库红旗表无甲状腺专行·如实记）。

依据与边界：以上为模型级生活参考（非诊断）；抗甲亢与替代治疗的选择、剂量、停药一律归内分泌科；本卡零方案零剂量。

⑳ 痛风发作怎么办？

一句话答案：痛风是尿酸在关节里结晶成刺（比喻）——急性发作先就医定方案，缓解期靠少高嘌呤饮食、多喝水、慢慢减重，把复发频率往下压。

分情况

  1. 大脚趾根半夜红肿热、疼得不敢碰（典型发作方向）——就医确诊；急性期抬高患处、冷敷可助缓解（模型级通行护理）；止痛与降尿酸方案一律归医生。
  2. 不发作的缓解期——库锚卡（关联 906 度）为机制层研究照录；饮食方向=少内脏与浓肉汤类、限酒尤其啤酒、多喝水（模型级通行·具体量与个人目标归医生/营养师）。
  3. 体重往下走是根本杠杆之一——但快速断食反而可能诱发发作（模型级·如实标）：小步慢减，见减重卡。
  4. 常与血压、血糖、血脂问题结伴——整体代谢面一起管（见血压卡与血糖卡），别只盯尿酸一个数字。

红旗线（立即就医）

  • 多个关节同时红肿痛伴高热 → 当天就医排除关节感染（模型级通行红旗·库红旗表无痛风专行·如实记）。
  • 胸痛压榨感/放射至臂颌、突发一侧无力口齿不清 → 立即急救（红旗表行1/行2·代谢共病急症同口径）。

依据与边界：以上为模型级生活参考（非诊断）；急性期用药与降尿酸治疗一律归医生；本卡零药名零剂量。

㉑ 血糖高/糖尿病怎么办？

一句话答案：血糖问题的主线是「受体被持续刺激磨钝了」——前期靠真食物、每天动、减内脏脂肪还有窗口；确诊后治疗归医生，别把希望押给「一劳永逸」的说法，也别擅自停药。

分情况

  1. 体检临界偏高、还没到糖尿病（前期方向）——库内前期专卡在库（399 度）；窗口期是资产：吃真食物（律3·证据级 A）加每天运动（律2·A）加腰围慢慢往下走（模型级转写）。
  2. 已确诊、在治疗中——治疗面零转写；能自己做的底座同上，再加律4 间歇与留白（B+·机制强）：进食留出空档，不给身体「持续刷屏式」的刺激；监测线归医生。
  3. 想找「一劳永逸」的办法、或用保健品替代治疗——库面没有这样的证据（如实标）：指标正常是治疗在起效，停不停、怎么停归医生。
  4. 新出现乏力、多饮多尿、体重莫名降——先就医查清，别先自我归因。

红旗线（立即就医）

  • 突发呼吸困难 → 立即急救（红旗表行3·急症面）。
  • 呼气烂苹果味+极度乏力+腹痛（酮症方向）、意识模糊 → 立即急诊（模型级通行红旗·库红旗表无血糖专行·如实记）。

依据与边界：以上为模型级生活参考（非诊断）；降糖方案、胰岛素与监测目标一律归医生；本卡零药名零剂量。

㉒ 总是过敏（鼻炎/风团/皮疹）怎么办？

一句话答案：过敏是免疫系统把无害的东西当敌人报警（比喻）——鼻炎方向护屏障减刺激，皮疹方向记日记找诱因；最要紧的是学会认全身过敏反应，那是分钟级急症。

分情况

  1. 晨起连打喷嚏、清水鼻涕、眼痒（鼻炎方向）——库卡逆操作=律3 吃真食物加律4 间歇与留白（照录）；床品勤洗晒、花粉季关窗、回家洗脸换衣（模型级通行护理）。
  2. 风团时起时消、来得快退得快（荨麻疹方向）——库锚卡在库（371 度）；记「吃了什么、碰了什么—发作」对照日记；反复超过六周就就医查面。
  3. 一接触某物就起疹——见皮肤卡（接触性皮炎方向），找诱因优先。
  4. 诱因明确但躲不开——脱敏治疗面归医生评估，本卡不展开。

红旗线（立即行动）

  • 嘴唇舌头咽喉肿、全身风团伴憋气 → 立即急救（红旗表行9·过敏全身反应喉头水肿·肾上腺素笔如有立即用·分钟级恶化）。

依据与边界：以上为模型级生活参考（非诊断）；抗过敏方案与脱敏治疗一律归医生；本卡零药名。

㉓ 贫血是怎么回事/怎么补？

一句话答案：贫血不是一个「补」字能概括的——先查清是缺铁、缺别的还是慢性失血在暗处漏，补错了没用，还可能耽误找到真正的失血口。

分情况

  1. 脸色苍白、乏力、爬楼气喘（缺铁方向·女性月经量大时常见）——就医查血常规与铁代谢；库内主锚卡（关联 1280 度）为机制层研究照录；食源铁方向=红肉、动物血、深绿菜配维C 同餐（模型级）；补剂用不用、用多久归医生。
  2. 手脚发麻、舌炎、或年纪大吃素（另一类营养方向）——机制不同补法不同，先查清再补，不猜。
  3. 有痔疮、月经量特别大、或长期吃某类胃药——找到暗处的失血口比补更重要，归就医面。
  4. 不查先自行大补——不做（模型级安全提示：不缺而补未必无害）；查什么、补不补、补多久归医生。

红旗线（立即就医）

  • 拉黑色柏油样便、呕血 → 急诊走消化道出血路径（红旗表行7·急症面）。
  • 胸痛压榨感/放射至臂颌、突发呼吸困难 → 立即急救（红旗表行1/行3·重度贫血心脏负荷面同口径）。

依据与边界：以上为模型级生活参考（非诊断）；库内缺铁专项生活卡覆盖薄（UNKNOWN 如实标·宁缺勿编）；补剂种类与疗程一律归医生。

㉔ 红斑狼疮怎么办？

一句话答案：狼疮是免疫系统认错敌人打自己人的全身性疾病（比喻）——它是需要长期随访管理的病，不是绝境：规律复诊、防晒、别擅自停治疗，是病友能攥在手里的三件事。

分情况

  1. 反复关节痛+脸颊皮疹+口腔溃疡+说不清的疲劳（待查方向）——尽快风湿免疫科确诊，不在网上对症状；库锚卡（关联 938 度）为机制层研究照录。
  2. 已确诊——生活底座=睡足（律1）、严格防晒、感染早处理（模型级通行·光敏与诱因方向）；治疗方案零转写，一律归主治团队。
  3. 尿泡沫变多、腿脚浮肿加重（肾脏受累方向）——库内有肾脏 companion 卡（448 度）：这条线当天就医，不拖不赌。
  4. 备孕怀孕——归风湿科加产科双面共同管理，本卡不展开。

红旗线（立即行动）

  • 突发一侧无力/口齿不清/面瘫 → 立即急救并记录发病时间（红旗表行2·急症面）。
  • 胸痛压榨感/放射至臂颌 → 立即急救（红旗表行1·急症面）。
  • 新发剧烈头痛伴意识改变、尿量骤减浮肿快速加重 → 当天就医（模型级通行红旗·库红旗表无狼疮专行·如实记）。

依据与边界：本卡=认识与陪伴卡；库内生活法层覆盖薄（UNKNOWN 如实标·宁缺勿编）；一切诊断与治疗决定归风湿免疫科。

㉕ 骨质疏松怎么防？

一句话答案：骨质疏松是骨头里的存款被悄悄取空（比喻）——防的核心是负重运动、钙与蛋白从真食物里来、戒烟限酒；对长辈来说，防跌倒和防骨松同样救命。

分情况

  1. 绝经后女性、年长者（高发面）——库内有绝经后专卡（342 度）；要不要查骨密度、多久查，归医生安排。
  2. 动起来——方向是负重加抗阻加平衡：快走慢跑跳舞、靠墙蹲提踵、单脚站练平衡（律2 每日运动·证据级 A·具体处方按个人情况调整）。
  3. 吃——钙与蛋白优先从真食物来（律3·证据级 A）；补剂要不要加、加多少归医生。
  4. 已确诊或已发生过脆性骨折——治疗面零转写归医生；家里做防跌倒改造（夜灯、防滑、扶手、清地毯电线）是本卡能给的最硬一条。

红旗线（立即就医）

  • 摔倒后髋部或腰背剧痛、站不起来 → 当天就医/急救（模型级通行红旗·库红旗表无骨质疏松专行·如实记）。
  • 身高变矮超过四厘米、驼背快速加重 → 当天就医评估（模型级通行红旗）。

依据与边界：以上为模型级生活参考（非诊断）；骨松治疗与检查频次一律归医生；本卡零药名零剂量。
