⑨ 疼了很久一直不好（慢性痛）怎么办？

一句话答案：疼超过三个月，往往不再是「哪里坏了还在报警」，而是身体自己的报警器被调得太灵敏——疼是真的，不是你想多了；它值得被认真对待，而不是硬扛。

分情况

  1. 查了几次也没查出「大病」，可就是天天疼——先停止两件事：硬扛，和自责。能做的基线：睡足 7-8 小时、白天见自然光、进食规律、温和规律活动。
  2. 越疼越不敢动——方向是温和规律活动，不是完全躺平；完全不动通常让疼住得更牢。具体怎么动，请医生或康复师给方案。
  3. 夜里疼得睡不好——先保住睡眠节律：固定起床时间、睡够时长；睡眠被拆掉，第二天对疼的耐受力通常更低。
  4. 长期慢性痛和神经痛常相关——值得一并读「像过电一样的疼」那张卡。

红旗线（立即就医）

  • 疼痛伴胸痛压榨感/放射至臂颌 → 立即急救（心梗黄金时间以分钟计）。
  • 伴突发一侧无力/口齿不清/面瘫 → 立即急救并记录发病时间。
  • 疼痛持续加重、开始吃掉睡眠和工作 → 尽快专业评估。

依据与边界：以上为模型级生活参考（非诊断）；慢性痛的评估与治疗一律归医生。

⑩ 腰疼怎么办（久坐/劳损型）？

一句话答案：很多腰痛不是腰椎「断」了，是撑腰的肌肉被久坐一点点「饿」没了——出路通常是找回运动梯度，而不是躺得更久。

分情况

  1. 坐久了起身直不起腰——起身频率比下班后猛练一次更对路：间隔一阵就站起来走几步；睡足与吃真食物是底座。
  2. 疼得完全不敢动——方向仍是温和规律活动；长期一动不动卧床不在建议方向内，具体限度归医生。
  3. 疼顺着一侧屁股往腿脚方向窜、伴麻或过电感——这可能提示坐骨神经走向的问题：这条线归就医评估，不做自助。
  4. 床垫和睡姿怎么挑——目前没有足够证据给统一答案，不替你猜；持续疼就就医。

红旗线（立即就医）

  • 腰痛伴大小便失禁、会阴部麻木、一条腿力量快速变差 → 立即急诊。
  • 摔倒外伤后的腰痛、伴发热、伴不明原因消瘦的腰痛 → 当天就医。
  • 胸痛压榨/突发一侧无力/口齿不清 → 按急症急救口径处理。

依据与边界：生活建议为模型级候选；影像、诊断与治疗决策一律归医生。

⑪ 反复头痛怎么回事（紧箍型与偏头痛方向）？

一句话答案：大多数反复头痛是紧张型和偏头痛这两类「本身就在疼」的头痛，多数不危险；真正要警惕的是少数「长得不一样」的头痛——红旗线帮你划出来。

分情况

  1. 下午越干越紧、两侧像被勒了一圈——紧张型方向：睡足、起身喝水、让肩膀落下来是通行起点。
  2. 一跳一跳地搏动、怕光怕吵、动一动更疼——偏头痛方向：记发作日志（何时发作/吃了什么/睡了多久/月经周期），带日志就医效率高。
  3. 疼到恶心想吐、只能躺平——仍偏头痛方向，但达到这个强度值得让医生确认一次，别独自归因。
  4. 这次头痛和以前任何一次都不一样——先读红旗线，别套旧经验。

红旗线（立即就医）

  • 一生中最剧烈的头痛/雷击样头痛 → 急诊（雷击样头痛不是偏头痛）。
  • 高热伴颈部僵硬、畏光 → 急诊。
  • 头痛同时突发一侧无力/口齿不清/面瘫 → 立即急救并记录发病时间。
  • 50 岁后新发头痛、晨起加重的头痛、伴视物模糊或重影 → 尽快专业评估。

依据与边界：分型描述是帮你把话说明白再去就医，不是诊断；用药一律归医生。

⑫ 像过电一样的疼（神经痛）？

一句话答案：过电样、针扎样、火烧样的疼和普通酸痛不是一回事——那多半是神经自己在放电；这类疼越早让专业面确认，通常越少走弯路。

分情况

  1. 脸颊一闪一闪剧痛、刷牙洗脸吹风都能触发——三叉神经痛方向：直接就医，这条线不做任何自助尝试。
  2. 带状疱疹皮疹好了、疼还在——后遗神经痛方向：这不是「没好利索」，神经修复有自己的时间表；别硬扛，专业面有正规的评估路径。
  3. 长期病（如糖尿病）伴手脚麻痛、像戴了手套袜子——痛性神经病变方向：第一步是把原病的随访跟上，同时让医生评估神经的问题。
  4. 等评估期间——规律睡眠、安静的单点专注、持续学新这类支持性节律是稳法子，是陪伴不是治疗替代。

红旗线（立即就医）

  • 胸口的疼永远先排除心脏：胸痛压榨/放射至臂颌 → 立即急救。
  • 面部疼伴面部无力或口齿不清 → 立即急救。
  • 疼痛进行性加重、开始吃掉吃饭睡觉 → 尽快专业评估。

依据与边界：方向描述非诊断；确诊与治疗一律归专业面。

⑬ 关节和肌肉的疼（膝髋肩颈）怎么办？

一句话答案：关节肌肉的疼多半来自「用得太单一」或「用得太少」——出路通常是温和地恢复多样活动，而不是彻底静养，也不是硬顶。

分情况

  1. 膝盖/髋部上下楼更疼、坐久了起步僵——骨关节炎方向：动与歇交替（每日温和运动+间歇留白），不是二选一；怎么动、动多少，请医生或康复面定。
  2. 肩颈僵痛、转头发紧——每小时起身、让脖子离开前伸姿势是通行起点。
  3. 关节又红又肿又热、还发烧——当天就医。
  4. 摔倒外伤后关节变形、完全动不了 → 急诊。

红旗线（立即就医）

  • 关节红肿热伴发热 → 当天就医。
  • 外伤后关节畸形/无法活动 → 急诊。
  • 胸痛压榨/突发一侧无力 → 按急症急救口径处理。

依据与边界：生活建议为模型级候选；具体运动方案与治疗一律归专业面。

⑭ 每个月那几天的疼（痛经）怎么办？

一句话答案：大多数经期疼是子宫在收缩做工，疼是真的，但「月月硬扛到停摆」不是它的默认设置；疼到影响生活的痛经值得被评估——这不是小题大做。

分情况

  1. 经期头一两天下腹坠痛——睡足、温和活动、真食物是生活底座；热敷是通行起点。
  2. 一年比一年重的痛经——进行性加重本身就是信号，值得妇科评估一次；评估是拿信息，不是「有事」。
  3. 疼到呕吐冷汗、或者不是经期也疼——就医面，不硬扛。
  4. 止痛药怎么用——本卡一字不谈；用不用、怎么用，归医生药师。

红旗线（立即就医）

  • 突发剧烈腹痛伴腹部硬如板 → 急诊（禁食禁水等救护）。
  • 经期外持续疼/进行性加重 → 妇科评估。

依据与边界：生活建议为模型级候选；用药话题零涉及，一律归医生药师。

⑮ 家人疼着，我能做什么（癌痛照护）？

一句话答案：这张卡是给陪着的你：今天，癌痛在正规医疗里是可以被管理的事；你能做的最有力的一步，是把疼痛如实、具体地带给医生——并且不动任何药。

分情况

  1. 他说「还行、忍得住」，你看着难受——帮他把疼记录下来：什么时候疼、哪里疼、多疼、持续多久；诊室里，一份具体记录胜过十句「还行」。
  2. 加药减药换药的念头——全部打住：任何用药调整归主治团队；你能替他做的是把观察带进诊室。
  3. 你自己快被拖垮了——照护者先保住自己的睡眠和饭，这不是自私；你的在场本身就是支持的一部分，哪怕只是坐在旁边。
  4. 临终照护、缓和医疗这些话题——归专业面，本卡不展开。

红旗线（立即就医）

  • 新发剧烈疼痛/疼痛性质突变 → 当天联系医疗团队。
  • 伴突发呼吸困难 → 立即急救。
  • 呕血或拉黑色柏油样便 → 急诊。

依据与边界：治疗与用药决定全域归本人与医生；本卡只覆盖照护沟通层。

⑯ 怎么停止胡思乱想/反刍？

一句话答案：反刍不靠「别想了」停下来——顺序是关键：先避源、再降速、后处理念头；写下来比想开有效，因为转写本身把被动挨打变成主动处理。

分情况

  1. 夜里停不下来/越想越清醒——三步序：先避源（给环境暴露设时段纪律）→再降速（进入低功耗状态让自主调节接管）→后修复；不先避源降速就直接处理念头，像在满载的机器上跑诊断，只会更热。
  2. 同一件事反复嚼——把困扰从感受转写成清楚的命题：担心什么+证据是什么+边界在哪；反复困扰正是尚未转写的信号。
  3. 越想越觉得失控——两栏清单：能控的只有自己的判断与行动，外部人事放进「管不了」栏；写完 24 小时内至少做一个可控行动。
  4. 胡思乱想的内容是「我不够好」——换评价轴：只和昨天的自己比那一点差值；不是做到了才配好受，是好受于其中所以能继续。

红旗线（立即行动）

  • 伴失眠超期/日功能受损 → 专业评估。
  • 自杀意念任何形式 → 立即联系危机干预热线或急诊。
  • 创伤类反刍不在生活方法适用域 → 归专业面。

依据与边界：方法为模型级候选；本卡不做「清空大脑」承诺——目标是从袭击转为可处理；创伤场景一律归专业面。

⑰ 到什么程度该求助专业？

一句话答案：最稳三条——伤害自己的念头=立即热线/急诊（硬线）；胸痛呼吸困难=先按急症口径排除（不自行归因）；数周不回落+功能失守=专业评估（换工具，不是失败）。

分情况

  1. 看时长——影响睡眠/工作的状态持续数周不回落。
  2. 看功能——上班/家务/关系开始持续失守。
  3. 看广度——从担心一件事扩到事事担心。
  4. 命中任何一条=专业评估面，答案不是「再撑撑」；这和发烧看医生一样正常。

红旗线（立即行动）

  • 自杀意念任何形式 → 立即联系危机干预热线或急诊——这是底线，不是建议。
  • 胸痛压榨/放射至臂颌、突发呼吸困难 → 立即急救——先按急症排除，不自行归因，宁可白跑。
  • 惊恐反复发作 → 专业面。

依据与边界：分诊线索为模型级；是否需要干预由相应专科评估，生活方式方案不能替代专业干预。
