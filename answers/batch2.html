① 为什么总是这么累？（疲劳分诊）

一句话答案：疲劳是信号不是病名——先沿睡眠、情绪、躯体三条线自查两周，再决定找哪科的医生。

分情况

  1. 睡够了白天仍困、打鼾重——睡眠线：查睡眠呼吸暂停（见睡眠卡）。
  2. 提不起劲、以前喜欢的事也没兴趣——情绪线：想到情绪耗竭/抑郁面，见焦虑与情绪卡。
  3. 伴脸色苍白、女性月经量大——躯体线：想到贫血，就医查血常规，别自行大补铁。
  4. 说不清哪条线——记两周「疲劳日记」（睡眠时长/情绪/身体症状），带着记录就医效率最高。

红旗线（立即就医）

  • 体重骤降、夜间盗汗、便血 → 尽快就医排查。
  • 疲劳伴持续胸痛、气短 → 立即急诊。

依据与边界：模型级候选（非诊断）；「累」的机制覆盖薄处如实标注未知；慢性疲劳的专用评估归医生。

② 焦虑到什么程度该求助？

一句话答案：焦虑本身是正常的报警系统；当它影响吃饭、睡觉、上班，且持续数周不退，就是求助线。

分情况

  1. 有明确压力源、事过焦虑退——正常反应，自助方法够用（呼吸、书写、运动，见第一批焦虑卡）。
  2. 没有明确原因也慌、或事过仍慌——观察频率与持续时间，超过两周开始挤占生活=考虑求助。
  3. 开始回避正常社交/工作/出门——功能受损信号，尽快找专业帮助。
  4. 身体反复报警（心悸、手抖、失眠）查体无大碍——焦虑的躯体面，同样值得专业评估。

红旗线（立即行动）

  • 自伤念头任何形式 → 立即联系危机干预热线或急诊。
  • 惊恐发作连续不断、无法缓解 → 尽快就医。

依据与边界：模型级；「何时求助」的分界为行为学归纳，个体差异大，拿不准=问专业人士，问询本身不需要病情达到某个标准。

③ 什么值得爱？关系里怎么不丢自己？

一句话答案：好关系的两条判据——在关系里能做真实的自己，冲突之后能修复；两者缺一，就要警惕。

分情况

  1. 在某人身边总要表演另一个自己——这不是「不够好」，是关系形态在消耗你。
  2. 吵完架能和好、和好后更明白彼此——修复比磨损快，是好关系的心跳（见第一批关系卡）。
  3. 自己的朋友、爱好、时间全部让位给对方——自我边界在流失，先一项一项捡回来。
  4. 对方用爱包装控制（查手机、断你社交、贬低你）——这是控制不是爱。

红旗线（立即行动）

  • 关系中出现暴力、威胁、控制 → 寻求专业帮助与求助专线（本卡不适用该情境）。
  • 任一方出现自伤念头 → 立即危机干预热线或急诊。

依据与边界：多为观察性模型级；「值得的爱」不做价值强加——判据帮你识别形态，选择权在你。

④ 意义感没了怎么办？

一句话答案：意义感不是等来的，是练出来的——传承行为（带人、留存、创造）加微小目标续接，是最可控的两条路。

分情况

  1. 觉得日子重复无新意——先看身体：睡眠不足与长期压力会直接压扁意义感，先修睡眠（见睡眠卡）。
  2. 大目标落空后空虚——把「意义的来源」从单一目标挪到传承行为：带一个人、留下一件东西、创造一件小事。
  3. 什么都提不起劲——微小目标续接：小到不可能失败的一步（5 分钟），完成感是意义感的火种。
  4. 长期空虚且说不清为什么——值得做一次专业评估，空虚有时是情绪健康的信号。

红旗线（立即行动）

  • 持续空虚伴睡眠食欲改变超过两周 → 寻求专业评估。
  • 自伤念头任何形式 → 立即危机干预热线或急诊。

依据与边界：概念为事实级整理，方法为模型级；意义感的个体差异极大，本卡不做价值强加。

⑤ 我这样的人活着有什么用？（存在之问）

一句话答案：存在价值不是产出函数——先把「用」（你能产出什么）和「值得」（你本身）拆开，问题就松动了。

分情况

  1. 用「有没有用」给自己打分——那是把人当工具的算法；婴儿、重病者、老者的价值从不靠产出。
  2. 低谷期觉得自己没贡献——贡献有波动，价值没有；低谷时的任务是恢复，不是证明。
  3. 比较中觉得自己平庸——「值得」不参与排名；你关心的、爱你的具体的人，就是不可替换的证据。
  4. 这个问题反复出现且沉重——把它带给专业倾听者，沉重的存在之问值得被认真接住。

红旗线（立即行动）

  • 自杀意念任何形式 → 立即联系危机干预热线或急诊（硬红线，不犹豫）。

依据与边界：概念级整理（事实级概念+模型级方法）；本卡不替任何人回答「人生意义」，只提供拆解问题的杠杆。

⑥ 时间永远不够用怎么办？

一句话答案：时间贫困先补「睡眠保护窗」再谈效率——睡眠被砍是倒下的第一张多米诺，效率技巧救不了欠觉的人。

分情况

  1. 用睡眠换时间（熬夜赶工/刷手机）——这是负利率借贷：借 1 小时，白天还 2 小时的状态。
  2. 事务多到排不下——先分「必须本人做的/可以放弃的/可以延后的」，多数清单第一眼就能删掉三分之一。
  3. 全天被切碎、没有整块时间——保护一个最小整块（哪怕 30 分钟）给最重要的事，其余碎片化处理。
  4. 长期睡眠不足 6 小时且白天功能受损——先就医评估，这不是时间管理问题。

红旗线（立即就医）

  • 长期睡眠被严重压缩且日间功能明显受损 → 就医评估。

依据与边界：模型级；本卡的文献面尚待补全（如实标注未知）；睡眠保护窗的生理依据见睡眠卡与睡眠卷。

⑦ 玩（娱乐）真的有用吗？

一句话答案：有用——玩乐是恢复不是浪费；主动休息（切换注意力）比被动刷屏更能把状态还给你。

分情况

  1. 玩完更累（刷短视频两小时）——那是被动刺激不是休息：注意力被继续占用，恢复没有发生。
  2. 玩完真放松（运动、手工、真人桌游、出门）——主动休息：切换注意力通道，系统才能真正复位。
  3. 觉得玩有负罪感——恢复是生产力的一部分：不会休息的系统跑不远（见疲劳分诊卡）。
  4. 只在虚拟世界有快乐、现实全无——留意情绪面，快乐来源单一化值得自查（见焦虑卡）。

红旗线（立即就医）

  • 本卡为生活方式级，无急症红旗线。

依据与边界：模型级候选；「主动休息优于被动刷屏」的机制证据为观察性归纳，个体差异如实尊重。

⑧ 甲状腺结节报告怎么看？

一句话答案：结节不等于癌——绝大多数结节终生无害；先看报告上的 TI-RADS 分级，再按分级定随访节奏，不自己吓自己。

分情况

  1. 报告写 TI-RADS 1-2 类——良性表现为主，按医生建议的常规间隔复查即可。
  2. 报告写 3 类——可能良性，通常需要定期随访（间隔听医生的）。
  3. 报告写 4 类及以上——需要进一步评估，带完整报告就诊，不要拖延也不要恐慌（4 类≠癌）。
  4. 任何分级+功能症状（心慌、怕热、乏力、体重变化）——加查甲状腺功能，内分泌科评估。

红旗线（尽快就医）

  • 声音嘶哑、颈部迅速肿大、呼吸或吞咽困难 → 尽快就医。

依据与边界：模型级知识整理；分级解读与随访方案一律归医生，本卡只帮你读懂报告在说什么。

⑨ 腰痛要不要拍片？

一句话答案：多数腰痛 4-6 周自限——渐进活动优于卧床；拍片有明确指征，没有红旗线的腰痛通常先观察治疗，不急拍片。

分情况

  1. 扭了下、酸胀痛、没有下肢症状——先渐进活动：能走就走、能动就动，避免长期卧床（恢复更快）。
  2. 痛超过 4-6 周不退或加重——就医评估，由医生决定是否影像检查。
  3. 反复发作的久坐腰痛——查工作姿势与核心力量：椅子、站姿、每天快走，比片子先看（见疼痛卷）。
  4. 有下面红旗线任何一条——不要观察，立即急诊。

红旗线（立即急诊）

  • 下肢无力、鞍区（会阴部）麻木、大小便失控 → 立即急诊。
  • 外伤后腰痛、或伴不明原因体重下降/夜间痛醒 → 立即急诊。

依据与边界：模型级；「要不要拍片」由医生按指征决定，本卡只提供就诊前的时间观与活动观。

⑩ 总是睡不好怎么办？（升级入口）

一句话答案：先固定起床时间，再谈其他——作息锚是睡眠的第一杠杆；其余所有技巧都建立在锚之上。

分情况

  1. 入睡难、时睡时醒——先锚起床时间（含周末），白天见自然光，两周为一片观察窗。
  2. 躺下脑子停不下来——只观呼吸起落；把担心的事写成字，约定明天处理（见第一批睡眠/焦虑卡）。
  3. 周末补觉越补越困——补觉补不回节律：与其周末狂睡，不如全周同一锚点+短午睡。
  4. 睡够时长白天仍重度嗜睡、打鼾重——查睡眠呼吸暂停，睡眠门诊评估。

红旗线（立即就医）

  • 睡眠中出现呼吸暂停、打鼾伴白天重度嗜睡 → 睡眠门诊。

依据与边界：行为方法为模型级候选；安眠药不作任何建议，开停药归医生；本卡为第一批睡眠卡的高频入口改写版。
