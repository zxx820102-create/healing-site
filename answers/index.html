① 为什么我胃疼？

一句话答案：多数胃疼与胃酸、饮食不规律、压力、烟酒和某些止痛药有关；反复疼建议先查幽门螺杆菌。

分情况

  1. 空腹/吃辣/酒后烧灼痛、反酸——规律三餐、睡前 2-3 小时不进食、少烟酒浓茶。
  2. 长期紧张时疼、检查没大问题——功能性问题常见：规律进食窗＋减压（见焦虑卡）。
  3. 吃阿司匹林、布洛芬类药后疼——可能是药物刺激，别自行长期吃，请医生调整。
  4. 反复疼、家里有胃病史——查幽门螺杆菌，阳性按医嘱规范根除。

红旗线（立即就医）

  • 剧烈腹痛伴肚子硬如板 → 急诊排除穿孔/急腹症。
  • 呕血或拉黑色柏油样便 → 急诊走消化道出血路径。

依据与边界：以上生活建议为模型级候选（非诊断）；红旗线来自急症面；诊断、根除方案、用药一律归医生。

② 为什么总是累？

一句话答案：最常见的累不是大病，是睡不够、动太少、吃不对、压力大；但持续累也要查贫血、甲状腺和睡眠呼吸暂停。

分情况

  1. 熬夜/睡眠债——先补规律睡眠：睡足 7-8 小时（证据级 A）。
  2. 越歇越累的久坐累——低强度动起来：每天快走等温和有氧（证据级 A）。
  3. 伴脸色苍白、女性月经量大——想到贫血：就医查血常规，别自行大补铁。
  4. 打鼾重、睡够了白天仍困——查睡眠呼吸暂停，就医评估。

红旗线（立即就医）

  • 突发呼吸困难 → 立即急救。
  • 疲劳伴胸痛 → 按急症面急救处理。

依据与边界：生活建议为模型级；慢性疲劳综合征机制覆盖薄（如实标注未知），就医面优先；贫血用药归医生。

③ 睡不着怎么办？

一句话答案：先守规律：固定起床时间、白天见自然光、睡前一小时离屏；躺下脑子停不下来就只观呼吸，超过三周仍差就就医。

分情况

  1. 入睡难、脑子停不下来——睡前 10 分钟只观呼吸起落，念头来任它过去不追问（守静是让系统复位，不是用力清空）。
  2. 睡够时长白天仍困＋打鼾——查睡眠呼吸暂停。
  3. 轮班/时差型——节律被打乱：锚定固定起床时间＋晨间见光，比早睡硬躺有效。
  4. 因担心的事睡不着——先分「能做的/管不了的」，写下来明天处理（见焦虑卡）。

红旗线（立即就医）

  • 夜间憋醒伴突发呼吸困难或胸痛 → 立即急救。

依据与边界：行为建议为模型级候选；安眠药不作任何建议，开停药归医生。

④ 怎么放松/缓解焦虑？

一句话答案：焦虑多是「想象里的危险」在报警：放慢呼吸、把担心写成字分成「能做/管不了」、动身体、见真人；影响生活就找专业帮助。

分情况

  1. 事情还没发生、脑内放灾难片——痛苦分被夸大的/被提前的/不该有的；问一句「眼下真的有什么坏了吗」。
  2. 心跳快、手抖、坐不住——用呼吸当杠杆：慢而深的呼气（呼吸是唯一自上而下的自主神经开关，心率变异性机制）。
  3. 同一类烦心事反复来——把模糊情绪写成清楚的句子，写清了它就从「袭击你」变成「可处理的事」。
  4. 为管不了的大事担惊受怕、吃不下睡不着——先把「管不了」如实标出来，情绪随之撤出，把力气挪回能做的一小步。

红旗线（立即行动）

  • 自杀意念任何形式 → 立即联系危机干预热线或急诊。

依据与边界：生活方法为模型级；诊断与药物一律归专业面。

⑤ 怎么降胆固醇？

一句话答案：先查一次血脂拿基线；降胆固醇靠长年「真食物＋每天动＋减内脏脂肪」，数值高或有心血管风险时按医嘱用药，勿自行停。

分情况

  1. 体检轻度偏高、无其他病——食物换真的：少油炸少精制糖，规律进食窗（证据级 A·流行病学）；每天动（证据级 A）。
  2. 同时有高血压/糖尿病/吸烟——风险是叠加的，就医做整体心血管评估，别只盯一个数字。
  3. 家里有人年纪轻轻就心梗、或体检见肌腱黄色瘤——警惕家族性高胆固醇，必须就医，单靠饮食不够。
  4. 吃药后指标正常想停药——那是药在起作用；停不停、怎么停归医生，自行停易反弹。

红旗线（立即就医）

  • 胸痛压榨感/放射至臂颌 → 立即呼叫急救。

依据与边界：生活方式建议为模型级候选；具体降脂方案与目标值证据不足，就医面优先（医生/注册营养师）。

⑥ 怎么减肥不反弹？

一句话答案：不反弹的关键不是猛减，是换成能住一辈子的习惯：真食物、规律进食窗、每天动、睡够；慢慢减才是快。

分情况

  1. 反复节食-反弹循环——猛招是持续强刺激，身体会脱敏适应；改小步可持续版：从「每餐一半真食物」开始。
  2. 觉得任务太大不知从哪开始——切到 5 分钟能做完的一片，先动再说（大事作于细）。
  3. 越减越自责、破戒就放弃——自我谴责不利健康；自我接纳反而让改变可持续。
  4. 伴打鼾白天嗜睡、或皮肤褶皱处发黑——就医查睡眠呼吸暂停与血糖代谢面。

红旗线（立即就医）

  • 过度节食后心悸、晕厥、突发呼吸困难 → 按急救路径就医。

依据与边界：全部为模型级候选；减重药物与手术一律归专业面评估。

⑦ 血压高怎么办？

一句话答案：单次测量高不算数——居家早晚各测一次记录成线；确诊后靠少盐、常动、睡够、遵医嘱用药把整条线拉平，别凭感觉停药。

分情况

  1. 体检临界偏高（高血压前期）——先生活面：每天温和有氧＋给紧张系统留回落空档，再复测。
  2. 已确诊在服药——三件事：常动让血管随节律舒缩、深睡给血管留修复窗、钠与压力刺激间歇化；重点看居家自测的节律曲线而非单次数值。
  3. 年轻就高或家中多人高血压——就医排查继发原因，不是「年纪问题」。
  4. 吃药后正常想停药——数值正常=治疗在起效；调药停药归医生，凭感觉停易反弹出事。

红旗线（立即就医）

  • 胸痛压榨感/放射至臂颌 → 立即呼叫急救。
  • 突发一侧无力/口齿不清/面瘫 → 立即急救并记录发病时间（溶栓窗口）。
  • 突发呼吸困难 → 立即急救。

依据与边界：节律叙述为模型级候选；具体用药选择与目标值一律归专业面。

⑧ 爱是什么/怎么经营关系？

一句话答案：好的长期关系不靠不吵架，靠修复比磨损快：多说具体的感谢、吵架时好好开口、情绪上头先暂停，接受有些分歧会一直在。

分情况

  1. 总为小事吵到翻脸——盯正负互动比例：稳定的伴侣关系里正面互动约是负面的 5 倍以上；每天一次「具体」的感谢（感谢具体那件事，不笼统夸）。
  2. 一开口就指责、一被说就反击、慢慢互不理睬——四大破坏模式的解药：批评→用「我感受＋我需要」开头；防御→担自己那份；轻蔑→培养欣赏；冷战→说好暂停时长，到点回来。
  3. 吵到心跳加速、脑子发热——心率超 100 时人真的听不进话：暂停至少 20 分钟做点真平静的事（不是憋气冷战），再回来谈。
  4. 感情被日子磨淡——磨损恒在，健康=修复速率大于磨损速率；每周固定 15 分钟「状态会议」：感谢一件＋议题一件＋下周再约。

红旗线（立即行动）

  • 任一方出现自杀意念 → 立即危机干预热线或急诊。
  • 关系中出现暴力或控制 → 寻求专业帮助（本卡不适用该情境）。

依据与边界：多为观察性模型级（个别为事实级观察/生理）；伴侣治疗、创伤与暴力情境一律归专业面。
